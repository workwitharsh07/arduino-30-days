---

## Overview

**Arduino 30 Days** is a structured, project-based course created by **LifeTronix** to help beginners build a strong foundation in Arduino programming, electronics, and embedded systems.

Instead of learning only theory, you'll complete one practical lesson every day while understanding how real electronic circuits and Arduino programs work together.

Each lesson includes:

- Step-by-step explanations
- Circuit diagrams
- Complete Arduino source code
- Bill of Materials (BOM)
- Project images
- Practical challenges

## What You'll Learn

By completing this course, you will learn how to:

- Program Arduino using C/C++
- Build electronic circuits safely
- Understand digital and analog I/O
- Interface sensors and modules
- Control LEDs, buzzers, motors, and displays
- Develop complete Arduino-based projects
- Build confidence in embedded systems development

## Getting Started

1. Clone this repository.

```bash
git clone https://github.com/workwitharsh07/arduino-30-days.git
```

2. Open the Arduino IDE.

3. Navigate to the desired lesson inside the `course/` folder.

4. Upload the sketch to your Arduino UNO.

5. Follow the lesson documentation.
