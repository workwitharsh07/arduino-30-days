# 💡 Day 01 - Blink LED

> Learn the fundamentals of Arduino programming by creating your first blinking LED circuit.

---

## 📖 Overview

The Blinking LED project is the perfect starting point for learning Arduino. In this project, an LED connected to Pin 13 turns ON and OFF every second.

This project introduces digital outputs, Arduino programming, breadboard wiring, and safe LED connections using a resistor.
